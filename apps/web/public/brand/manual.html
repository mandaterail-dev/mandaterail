01

Brand idea

MandateRail is an open-source policy-gated settlement rail for Algorand agentic commerce: human-approved agent payments with institutional trust. The brand should feel like Folks Finance or the Algorand Foundation—calm infrastructure, not a casino DEX.

Direction locked: rail-check (two parallel rails + check notch). Alternate marks (mandate-seal, policy-gate, signed-ticket) are archived for reference only.

06

Incorrect use

Protect the mark. If it looks flashy, stretched, or playful, it is wrong.

Don’t stretch Keep aspect ratio. Scale uniformly only.
Don’t recolor arbitrarily Accent #2B5EA7 only—no rainbow or brand mashups.
Don’t add neon No glow, gradients, or cyber aesthetic.
Don’t drop shadows Flat mark on flat surfaces. No soft UI chrome.
Don’t rotate Rails stay horizontal—always level.
✓
Don’t separate rails from check The lockup is one unit; never rearrange parts.
✅ 🛤️
Don’t replace the check with emoji No ✅, ✔️, or track emoji as a stand-in for the mark.

08

Voice

Calm, precise, developer-respecting. Explain mechanisms; don’t sell vibes. Institutional trust over growth-hack energy.

Do say

“Approve the mandate before the agent can settle.”

Don’t say

“Unleash autonomous money printers on L1 🚀”

Do say

“Policy-gated settlement on Algorand TestNet.”

Don’t say

“The ultimate DeFi agent casino rail.”

  • Prefer short declarative sentences.
  • Name the control surface: mandate, approval, receipt, bridge.
  • No neon copy, no mascot voice, no FOMO.
  • Apache-2.0 and open-source posture when relevant—quietly, not as a badge farm.
