# MandateRail brand marks

**Brand manual (rail-check locked):** [manual.html](./manual.html) · [MANUAL.md](./MANUAL.md)

Original marks for the MandateRail console (Apache-2.0). Calm, precise, infrastructure — Folks/AF seriousness. No neon, no mascot.

**Lockup variants:** use **MandateRail** (one word) as the primary product name; **Mandate Rail** (spaced) is acceptable in prose and long-form docs.

Default console direction: **rail-check** (locked 2026-09-17).

---

## 1. rail-check

- **Rationale:** Two parallel rails with a subtle check/seal notch — conveys institutional rails + approved policy without looking like a bank logo clone.
- **Accent:** `#2B5EA7`
- **Neutrals:** `#0F1419` (ink) / `#F4F6F8` (paper)
- **Favicon:** Readable at 16–32px — horizontal bars + small check remain distinct; avoid dropping stroke below ~2.5px.
- **Files:** `mark-rail-check.svg`, `wordmark-rail-check-{light,dark}.svg`, `favicon-rail-check.svg`

## 2. mandate-seal

- **Rationale:** Circular seal/stamp with an abstract geometric M cutout (not letter soup) — policy authorization as a quiet stamp.
- **Accent:** `#1F6B6B` (calm teal)
- **Neutrals:** `#0F1419` / `#F4F6F8`
- **Favicon:** Outer ring + simplified M peaks; at 16px prefer filled ring weight over double rings.
- **Files:** `mark-mandate-seal.svg`, `wordmark-mandate-seal-{light,dark}.svg`, `favicon-mandate-seal.svg`

## 3. policy-gate

- **Rationale:** Abstract gate/brackets with a keyhole or approval slot — spend policy as a controlled passage.
- **Accent:** `#3D4F7A`
- **Neutrals:** `#0F1419` / `#F4F6F8`
- **Favicon:** Bracket sides + keyhole blob; keep keyhole solid at small sizes so it does not disappear.
- **Files:** `mark-policy-gate.svg`, `wordmark-policy-gate-{light,dark}.svg`, `favicon-policy-gate.svg`

## 4. signed-ticket

- **Rationale:** Ticket/stub silhouette with a thin rail line through it — signed receipt / mandate as a pass.
- **Accent:** `#4A5D4E` (muted green-gray)
- **Neutrals:** `#0F1419` / `#F4F6F8`
- **Favicon:** Ticket outline + rail; perforation can be omitted below 20px if needed.
- **Files:** `mark-signed-ticket.svg`, `wordmark-signed-ticket-{light,dark}.svg`, `favicon-signed-ticket.svg`
